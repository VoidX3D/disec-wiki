## Maintainers

```
npm run convert   # rebuild markdown pages from source data
npm run download  # fetch more primary-source documents offline
npm run news      # save latest agenda-relevant articles offline
npm run build     # do all of the above + build the static site
npm run serve     # optional: static server + live-news RSS proxy on :8000
```

> **Offline use:** the built `site/` folder is fully self-contained — copy it to a
> USB drive or open `site/index.html` and everything works with no server.
